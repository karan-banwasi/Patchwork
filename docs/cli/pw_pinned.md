## pw pinned

List all pinned (ignored) packages

### Synopsis

Display all packages currently pinned in the Patchwork configuration.

```
pw pinned [flags]
```

### Options

```
  -h, --help   help for pinned
      --json   Output pinned packages in JSON format
```
