## pw history

Show or clear upgrade history

### Synopsis

Display past package upgrade runs recorded by Patchwork, or clear the stored history.

```
pw history [flags]
```

### Options

```
      --clear            Clear all recorded upgrade history
  -h, --help             help for history
      --json             Output history as JSON
  -n, --limit int        Maximum number of history runs to show (0 for all) (default 20)
  -m, --manager string   Filter history by package manager
```
