## pw config set

Set the value of a configuration key

### Synopsis

Set a configuration setting persistently. Supported keys: defaults.timeout, defaults.accept_agreements, defaults.trust_repository, defaults.no_refresh, disabled_managers, accept_agreements, pins, pinned_packages.

```
pw config set <key> <value> [flags]
```

### Options

```
  -h, --help   help for set
```
