## pw schedule

Manage scheduled background update checks and desktop notifications

### Synopsis

Configure, inspect, and execute periodic background update checks using your operating system's native user-level scheduler (Task Scheduler on Windows, launchd on macOS, systemd/crontab on Linux).

