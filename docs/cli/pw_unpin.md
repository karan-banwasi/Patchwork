## pw unpin

Unpin one or more previously pinned packages

### Synopsis

Remove one or more package IDs (or manager:id entries) from the Patchwork ignore list so their updates are shown again.

```
pw unpin <package-id> [package-id...] [flags]
```

### Options

```
  -h, --help   help for unpin
```
