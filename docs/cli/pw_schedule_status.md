## pw schedule status

Show scheduled check status or a status-bar summary

### Synopsis

Display the current scheduled background check state, OS scheduler registration status, and cached update summary.

```
pw schedule status [flags]
```

### Options

```
      --bar    Output a compact summary suitable for status bars
  -h, --help   help for status
      --json   Output schedule status as JSON
```
